# Política de Privacidad de Mítico Fitness **Última actualización:** Diciembre 17, 2025 ## 1. Introducción Morphis Digital ("nosotros", "nuestro") opera la aplicación móvil Mítico Fitness (en adelante, "la Aplicación"). Esta página le informa sobre nuestras políticas con respecto a la recopilación, uso y divulgación de información personal cuando utiliza nuestra Aplicación. ## 2. Información que Recopilamos ### 2.1 Información Almacenada Localmente La Aplicación almacena la siguiente información **únicamente en su dispositivo**: - **Rutinas de entrenamiento:** Ejercicios, series, repeticiones y pesos que usted crea - **Historial de entrenamientos:** Registro de sus sesiones de gimnasio - **Preferencias de la aplicación:** Tema (claro/oscuro), configuraciones generales **Esta información NO se envía a ningún servidor externo.** ### 2.2 Información No Recopilada **NO recopilamos, almacenamos ni compartimos:** - Datos personales (nombre, dirección, teléfono) - Información de contacto - Datos de ubicación GPS - Información de salud o médica - Datos biométricos - Información de tarjetas de crédito o pagos ## 3. Permisos de la Aplicación La Aplicación requiere los siguientes permisos: ### 3.1 Acceso a Internet (`INTERNET`) **Propósito:** Cargar códigos QR de pago desde GitHub y mostrar la ubicación del gimnasio en Google Maps. **Datos enviados:** - Solicitudes HTTP a `raw.githubusercontent.com` para descargar imágenes de códigos QR - Solicitudes a Google Maps API para mostrar mapas **Datos NO enviados:** Ningún dato personal. Solo solicitudes anónimas para recursos públicos. ### 3.2 Estado de la Red (`ACCESS_NETWORK_STATE`) **Propósito:** Verificar si hay conexión a Internet antes de intentar cargar códigos QR, mejorando la experiencia del usuario. **No se recopila ni envía información sobre su red.** ## 4. Servicios de Terceros La Aplicación integra los siguientes servicios de terceros: ### 4.1 GitHub - **Uso:** Almacenamiento de imágenes de códigos QR para pagos - **Datos compartidos:** Ninguno. Solo se descargan recursos públicos - **Política de privacidad:** https://docs.github.com/en/site-policy/privacy-policies ### 4.2 Google Maps - **Uso:** Mostrar la ubicación del gimnasio Mítico Fitness - **Datos compartidos:** Solicitudes anónimas de mapas - **Política de privacidad:** https://policies.google.com/privacy ### 4.3 WhatsApp (Enlaces externos) - **Uso:** Botones para contactar al gimnasio vía WhatsApp - **Datos compartidos:** Al hacer clic, se abre WhatsApp con un número pre-cargado. Los datos compartidos dependen de su uso de WhatsApp - **Política de privacidad:** https://www.whatsapp.com/legal/privacy-policy ## 5. Almacenamiento de Datos ### 5.1 Ubicación de los Datos Todos los datos de entrenamiento se almacenan **localmente** en una base de datos SQLite en su dispositivo, en la carpeta privada de la aplicación. ### 5.2 Seguridad - Los datos son accesibles solo por la Aplicación - Android protege estos datos con su sistema de permisos - No hay transmisión de datos a servidores externos ### 5.3 Copia de Seguridad La Aplicación permite exportar sus datos manualmente a un archivo en su dispositivo. Usted controla completamente estos archivos. ## 6. Eliminación de Datos Puede eliminar todos los datos de la Aplicación en cualquier momento: 1. **Opción 1:** Configuraciones → Datos → Restablecer datos 2. **Opción 2:** Desinstalar la aplicación (elimina todos los datos automáticamente) ## 7. Privacidad de Menores La Aplicación no está diseñada específicamente para menores de 13 años, pero no recopila información personal de ningún usuario, incluidos menores. ## 8.
